How approval routing works

The employee's Reporting manager is selected on the employee record. A workflow stage using Direct manager sends that employee's request to the reporting manager selected on the employee record.

1 Employee submits→2 Stages run in order→3 Final result is recorded
One managerStage 1 · Any one approver · Direct manager
Any one of several approversStage 1 · Any one approver · Designation or access role
All approvers togetherStage 1 · All eligible approvers · Designation or access role
Sequential approvalStage 1 manager, then add Stage 2 for the next approver
To match your manager process: Create the supervisor employee first. Create/assign their designation, then select that person as the normal employee's Reporting manager. Create a Leave workflow with Stage 1 set to Direct manager. Create an HR service workflow the same way if Other requests must also go to the manager.
